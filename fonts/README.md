# Fonts

`style.css` expects these four files here (all SIL Open Font License, from Google Fonts):

| File | Font | Used for |
|---|---|---|
| `andika-regular.ttf`, `andika-bold.ttf` | Andika | Print letters. Single-storey a, g, y. |
| `playwrite-gb-s.ttf` | Playwrite GB S | Cursive letters in tiles and boxes (unjoined). |
| `playwrite-gb-j.ttf` | Playwrite GB J | Joined cursive, used for the finished word. |

Licences are alongside (`OFL-andika.txt`, `OFL-playwrite.txt`). Downloaded 2026-11-21 from github.com/google/fonts.

If a file is ever missing the game falls back to Comic Sans / Chalkboard SE (print, also a round "a") and Snell Roundhand (cursive), so it still works.
